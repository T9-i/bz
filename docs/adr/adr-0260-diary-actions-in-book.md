# ADR-0260 日记本条目动作收进书内：标签选择器弹窗退役，便签菜单补「打开笔记」

- 日期：2026-10-26
- 状态：已采纳（部分取代 ADR-0017 的「标签选择器 / 加密条目改分类降级」入口）
- 相关：ADR-0230（整域换成「桌上那本」）、ADR-0233（写日记改书内写作页）、ADR-0017（加密条目分流）、ADR-0259（分卷）

## 背景

用户点便签菜单的「换张贴纸」，弹出来的是旧「回忆墙」时代的**另一层宿主弹窗**（「选择类型」，`uiModal` 挂在 `document.body`）：

- ADR-0230 把整域换成一本摊开的书之后，书里的动作全部是桌上实物（书口索引、台历、放大镜、贴纸册、火漆信封、撕页），只剩这一个浮层还在书外面、还盖在书上面——观感与口径都不搭。
- 书里的贴纸册当时只做了「按类翻」一半，开关键注释还写着「换贴纸走真标签选择器」，等于把一个本该在书里的动作寄存在书外。
- 那个弹窗还带「删除」入口与「加密条目改分类降级」分流，而这两件事在书里本来就有去处（撕页 / 拆信看 → 从信封取出）。

## 决策

1. **删掉标签选择器这层弹窗**：`showTagPicker` / `hideTagPicker` / `createTagPicker` 及其状态机、筛选框、`--split` 底栏、界面专属 CSS、`diary-tag-selector-*` 的滚动条通杀枚举与卸载兜底 id 一并退役。`dialogs.ts` 只剩写日记弹窗（命令 `bz-diary-write` 那条链路）。
2. **换贴纸 = 同一个贴纸册换一种摊法**：点文具是「按类重装订」（只列用过的贴纸，点一张筛一类）；便签菜单「换张贴纸」是「盖贴纸」（列全部可贴的，当前那几张先盖上，可选可摘，点「盖上去」落盘）。落盘走写层 `updateDiaryTags(date, filePath+time 谓词, tags, { filePath })`，结果经 `diary:tags-changed` 回刷整册；至少留一张。
3. **加密条目不再从弹窗降级**：它没有明文文件，换贴纸本来就不给（菜单里 `show('retype', !enc)`）。要还原成普通条目走「拆信看 → 从信封取出」，那条路一直有。
4. **便签菜单补「打开笔记」**（用户要求）：日记条目走本域 `jumpToDiaryEntry`（filePath 直开条目 md），影视/信/书打开自己那份 md（`filename` 即 vault 路径）。**先 `hide()` 再把笔记放出来**——书是整屏遮罩面板，不收起来笔记就被盖在书背后（「打开了但看不见」）。加密条目没有明文文件，菜单里不给这一项。

## 后果

- 书里的动作全部在书内完成，`document.body` 上不再常驻或临时挂本域任何浮层（写日记弹窗是命令入口，例外且一直是）。
- 「删除」只剩便签菜单「撕掉」一个入口（原本弹窗里那个只是第二个入口）。
- 条目动作入口由 6 项变 7 项：打开笔记 / 换张贴纸 / 收进信封 / 拆信看 / 从信封取出 / 誊录正文 / 誊录位置 / 撕掉（按条目类型显隐）。

## 备选（未采纳）

- **留着弹窗、只换一层书页皮**：书里已经有一本贴纸册，两处都能改贴纸，迟早出现两边不一致。
- **把「删除」也搬进贴纸册**：撕页是桌上实物，删除该走撕页的二次确认，不该跟贴纸混在一张纸上。
- **打开笔记不收起书**：Obsidian 会切到 md 视图，但书是整屏遮罩，用户看到的是「点了没反应」（面板还在最上面）。
