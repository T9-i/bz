# ADR-0254 小橘域的总闸：一个开关，关到「这一域不存在」

- 日期：2026-10-24
- 状态：已采纳
- 相关：ADR-0064（声明式设置 schema）、ADR-0202（通用页组序）、ADR-0069（smartcat 数据 sidecar 化）

## 背景

`smartcatEnabled` 这个键早就存在（l7A 引入），但它只管一件事：**启动时不自动挂载**。
关掉之后猫还在命令面板里，点一下又回来；设置面板那一页照旧；记忆流与行为流停不停，
取决于还有没有人去点那四条命令。用户这次要的是「把这只有点吵的猫关掉」——
一个开关能真的关停，而不是把音量拧到零。

## 决策

1. **不新开键。** `smartcatEnabled` 升格为域总闸，缺省 `true`（老用户零变化），
   落在设置面板「通用 → 功能域」一行 toggle。老键已在 `DEFAULT_SETTINGS` 里，
   一批测试夹具也在用它——再开一个 `smartcatDomainEnabled` 等于同一概念存两处，迟早对不上。

2. **关掉 = 四件事一起做**：
   - 启动不挂载（原有行为）；
   - 已挂载实例当场 `unloadSmartCat()`——摘猫容器、停常驻心跳、冲刷并停记忆/行为流、关三扇窗；
   - 命令面板撤下四条 `bz-smartcat-*`；
   - 设置面板导航撤下「小橘陪伴猫」页。

3. **生效点在 `saveSettings()`**，用「上次落到运行时的值」比对，不在 schema 的 `onChange` 里写副作用：
   core 的 schema 要保持 node 环境可加载（文案 lint 直接 import），不能反向依赖域；
   而面板开关、命令面板、手改 `data.json` 重载等路径最终都汇到 `saveSettings`，一次比对全覆盖。
   比对放在落盘之前——`saveData` 失败也照样把运行时拨到位（内存值已是用户意图）。

4. **装配口兜底。** `ensureSmartCat` 开头读 `smartcatEnabled === false` 直接返回。
   命令表能被外部 `runCommand` 绕过（主页.js 那类裸 id 调用），装配口是最后一道闸。

5. **数据不动。** `smartcat.json` / `smartcat-memory.json` / `smartcat-behavior.json`
   原样留在数据目录；关掉期间首页时间线仍读得到历史痕迹（它只读文件，不依赖域在跑），
   重新打开即接回。没有「关闭时清数据」这一步——关开关不该是不可逆动作。

6. **命令表运行时增删**用 `addCommand` / `removeCommand`——卸载路径早就在用的同一对 API。
   代价：命令被撤期间，用户给它绑的快捷键一并失效，重新注册后需要重绑。
   「关掉整个域」的语义下这个代价可接受，且只在关闭期间发生；域开着时零影响。

## 后果

- 关掉后命令面板、设置导航、桌面宠物三处一起消失，不会出现「关了但还能点开」的半关状态。
- 面板已经开着时拨开关，左侧导航不会立刻重建（下次打开面板才消失）；当前页与行本身即时生效。
- 将来要关别的域，往「功能域」组加一行即可——但每个域都得自己备好卸载路径与命令撤除，
  这组不是通用机制，只是一个语义位置。
