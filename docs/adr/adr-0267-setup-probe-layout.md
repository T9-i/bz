# ADR-0267 环境自检屏的返工：三段结构、两列排版、不给错误指引

- 状态：采纳
- 日期：2026-10-28
- 相关：ADR-0264（首次引导）、ADR-0265（分发硬化）、ADR-0266（面板返工）

## 背景

用户在真机上打开「设置 → 关于 → 环境自检」，截图暴露四件事：

1. 三个外部工具**在同一屏出现两次**：一次夹在环境行里，一次在「在线资源」组里；
2. 弹窗太窄，值列被挤成豆腐块；
3. 长值（Python 路径）被折到第二行、染成灰字，读起来像两条不同的信息；
4. 顶部描述在连不上资源站时教用户「① 填镜像源 ② 把 downloads/ 拷到 bz-offline/」——
   ① 指向的界面行已经在 ADR-0266 里下线了，② 让人手动摆文件位置本身就是错的指引。

## 决策

### 1. 检测屏分三段

`本机环境`（运行环境 / vault 路径 / 插件目录可写 / 数据目录可写 / Node / Python / AI）
→ `外部工具`（三个目录包）→ `在线资源`（文档 + 皮肤）。

- 工具行由 `core/env-check` 用 `runtimeDiagnostics()` 生成，id 带 `tool-` 前缀；
  `splitProbeRows()` 按前缀把两段切开（纯函数，可测）。
- 「在线资源」段由 `resourceDocsOf()` 过滤掉 `kind === 'bundle'`——目录包已经归「外部工具」，
  不在这里重复。
- 顺序上「外部工具」在「在线资源」之上，与设置面板的组序一致（同一件事在两处长得一样）。

### 2. 弹窗加宽 + 左右两列

- `uiModal` 的 `maxWidth` 600 → **760**：清单是「名称——值」两列，窄窗里右列只能挤成豆腐块。
- 行布局 `16px | minmax(140px,1fr) | minmax(120px,1.05fr)`：名称永远在左、值永远在右，
  **长值（路径）在自己那一列里换行**，不再整行折到下面。

  折行的老写法是为了绕开「右列被压成一字一列」的 bug；那个 bug 的真因是列宽 `auto`
  + `overflow-wrap:anywhere`（最小内容宽度退化成 1 字符），不是「值太长」。
  两列都给 `fr` 之后，折行就是多余的动作，而且它把一条信息拆成了两行、还换了颜色。

### 3. 连不上资源站时只说事实

`连不上资源站：下载类功能要等网络恢复后再用，插件主体不受影响。`

不再给「填镜像源」「把 downloads/ 拷到 bz-offline/」这类操作指令：

- 前者的入口已经从面板撤掉（ADR-0266），指过去用户找不到；
- 后者的失败模式很糟——位置摆错不会报错，只表现为「下载一直失败」，而用户会以为自己照做了。

真需要离线包的人（内网、无外网）本来就知道该怎么用；把这条写进面板只会误导更多人。

## 后果

- 同一屏里每件事只出现一次；三段的标题分别是「外部工具」「在线资源」，与设置面板同构。
- 路径类值仍是一行（真长到放不下时在自己那列内换行），不再出现「灰字漂在下面」。
- 新增测试：`splitProbeRows` 两段互斥、`resourceDocsOf` 排除目录包。
