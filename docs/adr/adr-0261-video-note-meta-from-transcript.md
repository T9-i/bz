# ADR-0261 视频文献的标题与简介只认转写文稿：切片任务不再吃整条视频的标题

- 日期：2026-10-26
- 状态：已采纳（补 ADR-0071 的元数据口径；视频文献 frontmatter 由九键变「九键 + 切片多一键 `clip`」）
- 相关：ADR-0071（AI 回迁插件侧）、ADR-0222（正文只剩「只修错」校对一档）、ADR-0122/issue 276（标题写成完整陈述句）、ADR-0073（四种文献类型）

## 背景

用户报：`文献盒/王虹证明三维挂谷集维数为三并解释转针问题.md` 的标题、简介与转写正文严重不符——正文通篇讲挂谷转针问题的来历（圆 → 等边三角形 → 八分之一圆 → 贝西科维奇 1928），一个字没提王虹，标题却写「王虹证明三维挂谷集维数为三」，简介写「介绍挂谷转针问题及王虹证明三维挂谷集维数为三的数学意义」。

查现场（`CONFIG/STORAGE/knowledge.json`）：该任务是切片任务，`start: 1:49 / end: 3:56`，转写正文 700 余字，正好是这 127 秒；A 面（转写）没问题，问题出在元数据这一跳。三条成因叠加：

1. 元数据提示词把**整条视频的标题**当依据写进首句（`基于下方 B站视频《…》的转写文稿片段`），而正文只是片段。模型看到标题点着「王虹到底证明了什么」，就把片段没讲到的结论补进了标题。
2. 视频元数据是四种文献里**唯一没有「不得超出材料」硬约束**的一类——段落（`只能来自原文，不得添加原文没有的事实`）与图版（`只能写图中确实能看到的内容，不得臆测`）都写了，视频只有一句「所有字段一律使用简体中文」。
3. 元数据只喂 `chunks[0]`（≤4000 字），正文却是全部块拼接——长转写时标题只反映开头，结论与落点常在结尾。

外加一条结构性问题：切片范围在笔记里**没有任何落点**（`sourceTitle` 是整条视频名，正文尾部只有 mp4 嵌入），所以「标题覆盖整条视频、正文只有 127 秒」这件事当事人事后无从察觉。

## 决策

1. **元数据加硬约束（与段落/图版同级）**：`标题与简介只能写转写文稿里确实讲到的东西——文稿没有提到的人物、事件、结论、数字，一律不得写进标题或简介；不得拿视频标题里的说法代替文稿内容`。
2. **切片任务不喂整条视频的标题**。`clip` 有值（`start`/`end` 任一非空）时，提示词里只给一句「本笔记只覆盖视频 `1:49-3:56` 这段片段，只描述片段本身」，视频标题一个字都不进。整片任务照旧给标题，但降级为 `【视频标题·仅背景参考，不是文稿内容】`。
   - 取「不喂」而不是「喂了再叮嘱」：模型对「背景」与「内容」的区分不稳定，而片段任务里整条视频的标题恰恰是**结论的先声**（「王虹到底证明了什么」），留着就是给它留了一张写结论的许可证。片段文稿自己会交代它在讲什么。
3. **元数据取样换 `metaExcerpt`**：单块直出；多块取「开头 3/4 + 省略号 + 结尾 1/4」，总长不超 4000。两头都看得到，长转写不再只凭开头起标题。
4. **覆盖范围落盘**：切片任务的笔记多一个 frontmatter 键 `clip: "1:49-3:56"`（`clipRangeLabel` 只拼接、不重排格式，与任务记录同口径；两端都空 = 整片 = 不落键）。正文仍严格等于转写原文，不掺说明文字。

## 后果

- 视频文献 frontmatter 从「九键」变成「九键 + 切片任务的一键 `clip`」；读侧（`parseFrontmatter`、预览、提炼成卡）对未知键本来就不做判定，存量笔记零迁移。
- 切片任务的标题不再能引用片段之外的结论；代价是片段从半句话开始时（例如 8:39 处开口就是「所以它其实是个反向过程」），标题会不如以前「顺」，但它是诚实的。
- `sourceTitle` 语义不变：仍是整条视频的标题（那是出处）；要判断「这笔记覆盖多少」，看 `clip`。
- 存量错标题不自动重写：AI 重跑一遍仍是同一份提示词才有意义，而重跑会重下视频。已在 `note-gen.ts` 注释与本 ADR 留档，谁再遇到就按此判。

## 备选（未采纳）

- **切片任务也喂标题、只加一句「仅供参考」**：本次事故正是模型把「参考」当成了「已知」，不赌。
- **元数据分两次调用（先判主题再起标题）**：多一跳延迟与一次失败面，换不来确定性。
- **正文开头写一行「本笔记覆盖 1:49–3:56」**：正文契约是「转写原文或校对稿」，掺任何说明都会污染下游（提炼成卡、挂载、同名文献对齐），覆盖范围是属性不是正文。
- **切片任务干脆不生成笔记**：用户要的正是「从一段视频里抠出一篇文献」，取消等于把功能砍掉。
