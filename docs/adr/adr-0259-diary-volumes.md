# ADR-0259 日记本分卷：一册一卷，目录覆盖全书

- 日期：2026-10-25
- 状态：已采纳（**取代 ADR-0258**）
- 相关：ADR-0258（按窗读盘，被本决策取代）、ADR-0170（墙数据预热 / 四目录并行 / 会话级缓存）、ADR-0171（开册进度条）、ADR-0231（撤销的「首屏窗口化」）、ADR-0233（书内写作页）、ADR-0064（声明式设置 schema）

## 背景

ADR-0258 把「慢」判在读盘上，于是**数据层**只读一窗 50 则。实施后发现两件事：

1. **慢的不是数据预处理，是 DOM。** 建块 + 离屏量高 + 切页 + StPageFlip 一次建两百多页，
   这几步随条目数线性涨；读盘虽然也要几秒，但它是进度条能给交代的那一段。
   裁读盘等于把快的省了、慢的一分没省。
2. **裁数据把功能一起裁了。** 册页索引（`monthMarks` 扫页里的日戳）、放大镜检索（扫页内块文本）、
   台历跳日（扫页找那天）全都建立在 `this.pages` 上。只读一窗之后，索引变成
   「自 2026-07-04 至 2026-10-25 · 凡五十则 · 四个月」——把十年日记记成了五十则。

用户拍板的话是：**「加载五十条日记，但是索引显示完整，搜索、查找都可以找到的，
性能在 DOM 渲染上，不是在数据预处理上」**，并且选定「只读一卷，再后台偷读剩下的」。

## 决策

1. **一册 = 一卷。** 书桌上摊开的永远是一卷，DOM 里的条目数由卷容量封顶（缺省 50）。
   卷界**落在月界**：从最新往前整月累加，凑够 ≥ 容量即收卷（单月自身超过容量时才在月内按容量切）。
   月度是索引的行单位，一行跨两卷会让目录自己先乱。
   卷号 1 = 最新那一卷。

2. **页码按卷重编。** 第 1 页 = 本卷第一页。跨卷的绝对页码编不出来（它需要全量分页，
   而那正是要省掉的东西），给一个算不出来的数字比不给更糟。

3. **数据仍然全量。** 开册先读到**第 1 卷收卷**为止（比 50 略多的有界读），随后后台把剩下的读进来
   （`fillWallEntries`）。读完时只更新索引 / 搜索 / 台历的覆盖面，**不重排书页**——
   用户当年否掉的就是「书自己变厚」。后台读盘期间索引页明说「目录还在读更旧的日子」。

4. **所有导航走同一个入口**：日期 / 月份 / 则序 → 卷 → 卷内页。册页索引、台历、检索命中三处统一，
   不再各自扫页。跳到窗外的东西 = 换卷 + 落在那一页，荧光笔照旧。

5. **册页索引是全书的目录。** 元数据行报全册（起止日期 / 总则数 / 月数 / 卷数 / 现在第几卷）；
   月行属于当前卷的写「第 N 页」，其余写「卷 N」，点了换卷并落到那个月。
   书口年份色带按**全册则数占比**画——它是「这本书有多厚」的缩影，不是导航。

6. **卷界允许漂移，不落盘。** 卷界每次由数据现算，新内容只进第 1 卷；某卷攒满整整一个月时
   后面的卷号整体 +1。影响限于卷号（卷内页码不受影响），为它引入一份要迁移的数据文件不划算。

7. **卷边界靠滚轮 / 键盘 / 竖向滑换卷。** 翻到卷尾再往后 = 下一卷第一页；
   翻到卷首再往前 = 上一卷最后一页（连续读不断线）。拖拽到头就停住——库的拖拽到边界不出事件，
   分不清「翻不过去」和「手势取消」，不猜。

8. **写完一篇立刻回册首。** `addEntry` 返回刚落盘的那一条，就地转成 `WallEntry` 插到内存首位，
   当场重排落第 0 页（50 则的重排是几十毫秒），不等防抖回刷。回刷只负责跟磁盘对齐，
   `pendingHome` 保证它不会把人带走。不演翻页动画——这是确认，不是表演。
   倒写（纸上「改日子」改到过去）例外：那一篇不在册首，落**它所在的那一卷那一页**，
   回册首等于写完看不见自己刚写的。

## 后果

- 常驻 DOM ≈ 一卷的条目数与页数，几百篇与几千篇的册子开起来一样重。
- 索引 / 搜索 / 台历的覆盖面 = 已读进来的数据：开册后一两秒内与旧版一致；这几秒里索引页会注明。
- 卷内页码从 1 开始，跨卷不连续；「第 N 页」只在当前卷内可读作导航。
- 卷号会随新日记漂移（每月最多整体 +1），索引里写的是「现在第几卷」。

## 备选（未采纳）

- **ADR-0258 的按窗读盘**：省的是数据不是 DOM，且把索引/搜索裁到窗口内。被本决策取代。
- **全量分页 + 窗口内容（215 个页壳，只填当前窗）**：页码跨全卷真，但「每块多高」要么全量建块量、
  要么建一套落盘的高度缓存（内容 hash + 版心宽 → 高），改字号/改宽度全得重算。
  为了一个装饰性数字引入第二个分页真理源，不划算。
- **固定每卷 50 则（不按月对齐）**：卷号可预测，但一个月会被切在两卷里，索引一行得写「卷 3–4」。
- **卷界沉淀到数据文件**：卷号永久不变，但最新那卷会一直长，DOM 又贵回来。
