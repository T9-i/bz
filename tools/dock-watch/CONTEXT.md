# Dock Watch

工具坞的离线值守进程 —— Obsidian 关着时按同一份规则表跑外部工具的常驻 node 程序。

**它没有自己的调度逻辑。** 判据、排班、起进程、判成功、记账全在 `dock-core.cjs` 里，
那是从 `src/dock/watch-core.ts` 打出来的同一份源码；插件里跑的是同一段 `tickOnce`。
契约 v2 起（ADR-0252），这个包只剩三件事：**装配**、**什么时候调一次**、**写本机状态**。

## Language

**值守进程 (dock-watch)**:
`tools/dock-watch/` 这个 node 程序本身。挂在 Windows 登录自启上的常驻进程，每 30 秒一拍。
**它不是工具坞工具**（工具是被调度方，它是调度方），所以不写 `manifest.json`、不进登记表。
_Avoid_: 守护进程, 后台服务, 定时任务

**自启动通道 (autostart channel)**:
值守「登录即启动」的两条路：计划任务 `bz-dock-watch`（首选，看得见、可 Start/Stop、失败重试 3 次），
以及注册被拒（标准用户上 `Register-ScheduledTask` 要提升的权限）时回退的
「启动」文件夹 `%APPDATA%\...\Startup\bz-dock-watch.vbs`。两者都指向同一份 `watch.vbs`，
卸载时两条都要清。
_Avoid_: 计划任务（那只覆盖首选那条）、开机启动项

**执行权锁 (execution lock)**:
`<数据目录>/dock.lock` —— 插件与值守**抢的同一把锁**（排他创建、90 秒不续期即过期、持有者每 20 秒续期）。
抢到的那个才调度，另一个这一拍什么都不做（`status.json` 的 `mode=busy`）。
**取代了上一版的「租约 / 让位」**：那是「我看见你在，我就让」的礼貌，不是互斥。
_Avoid_: 租约, 让位, 互斥锁（那是工具侧的事）

**判据核心 (dock-core)**:
`dock-core.cjs` —— 从 `src/dock/watch-core.ts` 打包出来的**整个零宿主依赖层**：
判据、视图、内核、一拍、执行、判定、锁、文件缝。**生成物**，改 `src/dock/` 就要重跑
`node scripts/build-dock-watch.mjs`。
存在的唯一理由是：调度只能有一份实现。
_Avoid_: 共享库, 核心包, 判据模块（它不止判据）

**在岗 / 离场 (in-session / off-session)**:
判据是**谁启动的**（契约 §4.4，ADR-0236 起）：bz 插件亲手拉起的（含它按规则自动触发）都是在岗，
有实时流、能停止；值守拉起的都是离场，只有记录。
_Avoid_: 在线/离线, 自动/手动（那是触发方式的轴，不是这一根）

**离线总闸 (watchdog switch)**:
`dock.json` 的 `watchdog` 键（缺省开）—— 只管**离场那一半**让不让值守接手。
与 `autoRun` 分两层：`autoRun` 是「自动运行」这个行为的开关（在岗离场都管），
两个都开才真的离场跑。开关只在设置页；设置页另有一行「值守状态」显示它此刻在不在跑。
_Avoid_: 值守开关（非 canonical，容易与它读的 `autoRun` 混）

**熔断 (breaker)**:
连续 3 次失败后台账里的 `pausedAt`。离场跑失败也会入账 —— 不然它会一直重试到天亮，
而用户第二天早上看到的是一串「失败」而不是「已经停了」。
_Avoid_: 暂停, 禁用

**网闸 (net gate)**:
值守**每一拍之前**的网络确认（`tools/dock-watch/net.js`）。TCP 直连公网 443 判链路，
最多等 5 分钟；等不到就**整拍不拍**（判据都不走，自然也不记账），把这次留给下一拍。
只离场这一侧有 —— 插件是用户自己打开的，值守的时刻由登录触发，不受控。
与「失败冷却」不是一回事：那记的是跑过之后的账，它管的是**还没跑**。
_Avoid_: 网络检测, 断网重试（重试是它的后果，不是它）

**值守状态 (watchdog status)**:
`%LOCALAPPDATA%\bz-dock-watch\status.json` —— 值守每拍刷新的体检快照（心跳、`mode`、本次启动跑了几次、
上次跑的是谁、上次的错误）。插件设置页读它回答「它现在到底在不在跑」。
**心跳超过 90 秒没更新 = 那个进程不在了**（一拍 30 秒，给两拍余量）。
两边各算一遍目录，口径靠 `tests/dock/watchdog-path.test.ts` 钉死。
_Avoid_: 租约, 在线状态
